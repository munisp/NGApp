Payment Switch JavaScript SDK

Vanilla JavaScript Integration Examples

Example 1: Simple Redirect Checkout

Click the button to create a payment session and redirect to the checkout page.

const paymentSwitch = new PaymentSwitch({
  apiKey: 'your_api_key_here'
});

// Create session and redirect
await paymentSwitch.checkout({
  amount: 5000, // $50.00 in cents
  currency: 'USD',
  description: 'Product Purchase',
  customerEmail: 'customer@example.com'
});

Example 2: Modal Checkout

Open the checkout in a modal without leaving your website.

const session = await paymentSwitch.createSession({
  amount: 7500,
  currency: 'USD',
  description: 'Premium Subscription'
});

paymentSwitch.openCheckoutModal({
  sessionId: session.sessionId,
  onSuccess: (sessionId) => {
    alert('Payment successful!');
  },
  onCancel: () => {
    alert('Payment cancelled');
  },
  onError: (error) => {
    alert('Payment error: ' + error.message);
  }
});
